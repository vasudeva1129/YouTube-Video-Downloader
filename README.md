# YouTube Video & Audio Downloader

A desktop application built with Python and Tkinter.

## Features

- Download YouTube videos (MP4)
- Download YouTube audio (MP3)
- Select download folder
- Simple graphical user interface
- Error handling

## Technologies

- Python
- Tkinter
- yt-dlp
- FFmpeg
